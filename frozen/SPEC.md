# W-CLV-P v1.0-R1 — FROZEN SPECIFICATION (approved for freeze by independent audit, with look-finalization watermark)
WCLVP_START = 2026-10-15T00:00:00Z (frozen; never moved)

0. Question: independent prospective test of whether the exact v1.1 wind tickets obtain positive line-aware CLV against the Pinnacle closing market. The historical W-CLV result is not treated as establishing that they should; positive, zero or negative CLV are all possible.
1. Sample: v1.1 entries (drakehinojosa/Wind---logger- log/entries.jsonl, hash-chained) with status LOGGED and qualified = true, K - 15 min >= WCLVP_START, subject to §14. PRE-WCLVP entries (K - 15 min < WCLVP_START) are outside the sample, not ERROR-NO-CLOSE, excluded from exclusion rates, counted separately. Leagues NFL and NCAAF (FBS-involved) as in v1.1; keyed by event_id. Historical 2021-2025 data and the 2025 S1 holdout never enter the statistic. If production is not live before WCLVP_START, uncaptured eligible windows are ERROR-NO-CLOSE; the start is not moved.
2. Relationship to v1.1: separate repository/process; reads v1.1 entries read-only (chain verified each use); never writes to v1.1; never reads v1.1 grades or any score source; reads v1.1 looks/<LG>_STOPPED only for §14. Each CLV record stores the SHA-256 of the exact v1.1 entry line.
3. Stored ticket (verbatim): book = ticket.book; side Under (UNDER-type); L_b = ticket.total; d = decimal(ticket.under_price) (a>0: 1+a/100; a<0: 1+100/|a|). No substitution.
4. Pinnacle close: live /v4/sports/{sport}/odds, regions=eu, markets=totals, bookmakers=pinnacle, oddsFormat=american; window [K-15m, K]; runs every 5 min; one sport-level call per run per sport with any admitted open window; capture time = UTC receipt time; authoritative close = latest valid capture in window; event match = v1.1 event_id with commence within 5 min of K, else X4-CLOSE.
5. Validity: Over and Under at the same point; capture time - 30 min <= last_update <= capture time. L_c = Pinnacle point; p_c = (1/d_U)/(1/d_U + 1/d_O).
6. Failure/retry: up to 3 attempts per call per run; no valid capture by K -> ERROR-NO-CLOSE; no backfill from later or historical data.
7. Exclusions (counted by league; no imputation; never replaced): ERROR-NO-CLOSE; X4-CLOSE; INVALID-TRANSFORM. PRE-WCLVP reported separately.
8. Frozen transform/tables (runtime-asserted; mismatch halts): s1_transform.py 806f9decf7825e202af33577f25478cb9586af269635ef37b12aa28b58427d4d; s1_residual_tables.json eeff6a1a8625dc867c955ae9f53678a46d04a0021fe70ae3c89ee26f8edacc43. NFL -> M2_NFL_totals; NCAAF -> M3_NCAAF_totals.
9. CLV: res = transform(table, "UNDER", L_b, d, L_c, p_c); CLV = W(d-1) - L, push = 0. Equal lines: price-only case. Different lines: frozen S1 half-point shift. Clipping as frozen (flagged, retained, counted). No outcomes used.
10. Estimator: per league mean CLV over the look's N; SE = sqrt(G/(G-1) * sum_g (sum_{i in g}(CLV_i - mean))^2)/N, clusters = US Eastern date of K; z = mean/SE. G<2 -> z undefined. SE=0: mean>0 -> +inf; mean<0 -> -inf; mean=0 -> 0. An undefined z cannot trigger z-rules; mean rules still apply.
11. NFL and NCAAF are independent mechanisms; no pooled test or decision.
12. Looks at N = 40, 80, 120 only; evaluable observations ordered by canonical K ascending, then event_id ascending; exactly the first N; excluded and PRE-WCLVP entries do not count toward N but stay in the accounting; no statistics between looks.
    LOOK-FINALIZATION WATERMARK: a look at N is computed only after (1) at least N evaluable observations exist AND (2) every admitted entry with canonical K <= the K of the provisional Nth evaluable observation has a terminal W-CLV-P record (EVALUABLE, ERROR-NO-CLOSE, X4-CLOSE or INVALID-TRANSFORM). Then the observations are ordered and exactly the first N evaluable are used. Once written, a look's membership is immutable.
13. Decisions per league: any look z >= 2.24 -> CLV GATE PASSED (stop that league, freeze, independent audit; no betting authority; no change to v1.1). Look 40: z <= -1.28 -> STOP: CLV NOT SUPPORTED. Looks 80/120: mean <= 0 -> STOP: CLV NOT SUPPORTED. Look 120 without gate -> STOP: CLV NOT DEMONSTRATED. Otherwise CONTINUE. STOP outcomes do not alter v1.1.
14. Admission is irrevocable once an entry is LOGGED+qualified, satisfies §1, and is written before that league's v1.1 looks/<LG>_STOPPED commit; such entries receive their close capture even if v1.1 later stops. Entries written after the STOPPED commit are not eligible. Each league runs until (a) a terminal §13 decision, (b) all admitted entries have passed K after a v1.1 STOP, or (c) the end of the 2028 season (implemented as K < 2029-03-01T00:00:00Z), whichever comes first. Stop before N=40 -> INSUFFICIENT N - NO DECISION; stop between looks -> last look's outcome, "stopped before next look". No extensions or added looks.
15. Artifacts: append-only SHA-256 hash-chained log/captures.jsonl (one record per sport-level call) and log/clv.jsonl (one record per admitted entry, after K); git history as audit trail; looks/<LG>_<N>.json with members; bug fixes documented, new hash, returned for audit when they could affect captures or CLV.
16. Prohibitions: no post-hoc changes to any element above; no alternative closing sources, books, subgroups, pooled tests, outcome-based analyses, historical/2025 data in the statistic, or rescue of STOP outcomes. Any redesign is a new protocol on unobserved data.
17. Budget: 1 credit per sport-level call; calls only while an admitted window is open (at most 3-4 runs per window; same-slot entries share calls); about <= 220 credits/season plus <= 2 per failed call for retries.
